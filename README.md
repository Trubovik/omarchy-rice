# Omarchy / Hyprland Rice & Custom Setup

Полная сборка кастомного окружения Linux (Omarchy / Hyprland), скриптов, хоткеев и списков пакетов для моментального развёртывания на чистой системе.

> **Важно:** Репозиторий исключает любые личные данные, пароли, токены, cookies, игры и историю браузера.

## Структура

* `config/` — Конфигурации окружения (`hyprland`, `omarchy`, `voxtype`, терминалы `alacritty`/`foot`/`kitty`/`ghostty`).
* `bin/` — Системные пользовательские скрипты и утилиты (`agy`, `agy-account`, `omarchy-agent`).
* `applications/` — Кастомные ярлыки приложений (`.desktop`).
* `packages/` — Списки установленных пакетов Arch (`pacman-packages.txt`) и AUR (`aur-packages.txt`).
* `home/` — Конфигурация шелла (`.bashrc`, `.bash_profile`).
* `backup.sh` — Скрипт сбора текущего состояния системы в репозиторий.
* `restore.sh` — Скрипт восстановления системы в один клик.

## Как развернуть на чистой системе

```bash
git clone <URL_РЕПОЗИТОРИЯ> ~/dotfiles
cd ~/dotfiles
./restore.sh
```

## Как сохранять новые изменения

В любой момент в терминале:
```bash
save-linux "Описание изменений (например: новая тема или хоткеи)"
```
или просто сказать агенту «сохрани сборку».
